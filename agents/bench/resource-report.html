How to read it

Throughput

Decode t/s — generation speed. Reading pace ≈ 5–10 t/s, so anything above streams smoothly.
Prompt t/s — how fast the model ingests context before it starts writing (noisy; varies with prompt length).
Wall s — end-to-end seconds for that single request.

Memory

Peak RSS / VmHWM — the model process's own resident / high-water RAM. Runs ~1.7–2.4× the file size (KV-cache + buffers).
VRAM — GPU memory held (laptop GPU rows only).
MemAvail min — lowest system free RAM during the run — the headroom that proves it fit.

Quality verdicts

Grounding — verbatim quotes / total quotes in the research answer. Each quote is checked as a literal substring of its cited source.
Search call / decline — did it call web_search when it should, and stay quiet when the note already answered?
Junk source — given sources that don't answer the question, does it abstain or invent a cited claim?

green good   amber weak but not harmful   red wrong / unsafe   grey not measured.   Grounding counts drift a little with the 256-token budget — the verbatim ratio is the signal, not the raw count. Source data: agents/bench/results.md · methodology: model-selection-research-2026-07-24-grounded.md.
