# Myrme 0.12.3 — the model runtime is unpacked with `zip` 9 (contract 1.10)

## What changes for people using formicaria

- **Nothing they will see.** The archive that brings the model runtime is unpacked by a newer version
  of the `zip` library, keeping the same rules about what is written and what is refused.

## What changes for formicaria

- **Nothing in the contract** (still 1.10). `fm-agent-run`'s `download` feature now needs `zip` 9,
  so a formicaria whose `fm-fetch` is also on `zip` 9 links one copy and can drop its `zip` waivers.
