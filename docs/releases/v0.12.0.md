# Myrme 0.12.0 — research from reputable sources only (contract 1.10)

## What changes for people using formicaria

- **`/research` reads only a list of reputable sources.** Public health bodies (MedlinePlus, the WHO,
  the NHS, the CDC, EFSA, the German health ministry's gesund.bund.de, BfR, DGE, the Swiss BLV,
  Santé publique France, ANSES, Italy's ISS EpiCentro); Wikipedia; papers through Europe PMC, arXiv and
  Crossref; code through Stack Overflow and GitHub. Nothing else is opened, and every source in a
  proposal says whose it is ("NHS (UK): Vitamin K").
- **The question decides where to look**, in English, French, German, Italian and Chinese. A health
  question reads MedlinePlus and the health bodies' own pages first; Wikipedia comes last, named
  *encyclopedia, not medical guidance*. "Papers on…", a DOI or a PMID reads Europe PMC, arXiv and the
  papers the Wikipedia article cites. A programming question reads Stack Overflow and GitHub.
- **Questions in French, German, Italian and Chinese are answered**: "à quoi sert la vitamine K",
  "Wie äußert sich Eisenmangel?", "il morbillo è pericoloso", "维生素K有什么作用" each get MedlinePlus,
  a body's page and Wikipedia in their language and in English.
- **"How much vitamin K in spinach" reads the app's own food list** too, with which table the value
  comes from and whether it was borrowed from another table.
- **No general search engine**: DuckDuckGo is no longer used anywhere.

## What changes for formicaria

- **Contract 1.10** (an addition): `VaultAccess::food(name)`, a provided method answering `None`.
  The desktop's `FmServe` answers it through `/api/food_search` and `/api/food_get`; the phone's vault
  access answers it with the same two commands in process. Without it `/research` works as before,
  without the food list.
- Pages of the listed bodies are fetched (only those, by a guarded fetch); the sources pack of their
  topic pages ships inside the crate (`sources.tsv`, 399 KB).

## Checked

- **Unit tests**: the list (scheme, port, user information, IP addresses, look-alike hosts), public

- **Live**, twelve questions: every health question answered by its bodies in 1.6–4.2 s; no source
