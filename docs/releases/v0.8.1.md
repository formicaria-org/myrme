# Myrme 0.8.1 — an integrated GPU no longer slows the laptop model down (contract 1.7)

## What changes for people using formicaria

- **On a computer whose only GPU is an integrated one, the assistant now runs on the CPU**, where it
  is faster. That includes a laptop whose discrete GPU is missing or has stopped working.
  - Measured on one laptop with the 4B laptop model: it wrote **14.4 tokens a second on the CPU against
    5.7 on the integrated GPU**, and read 95 against 80 (`docs/research/2026-10-23-integrated-gpu-fallback.md`).
  - The assistant's log says it once: *"only an integrated GPU (…) — the model runs on the CPU"*.
- **A discrete GPU is used exactly as before**, and so is every setting chosen by hand: `gpu = "on"` in
  the catalogue still uses any GPU, an integrated one included; `"off"` is the CPU.
- macOS is unchanged.

## What changes for formicaria

- Nothing to do. The contract stays **1.7**; the `models.toml` format and the `gpu` values are unchanged.
- Before starting the model, `agent-serve` runs the staged runtime's `llama-bench --list-devices` once
  (about 0.1 s here). If that cannot run or its output cannot be read, the start is as before.

## Checked

- Unit tests for the decision and for reading the runtime's device lines, including lines it must not
  take for a device.
- Against the shipped runtime: the device report still has the shape read here (a test pins it, so a
  runtime update that changes it fails rather than going back to the integrated GPU).
- End to end on a laptop with only an integrated GPU visible: the model server started with
  `--device none`, and the note appeared in the log.
- `pixi run ci` and `pixi run integration`.
