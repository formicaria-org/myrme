# Myrme 0.4.0 — the phone's facade, and the runtime an update brings (contract 1.3)

Superseded by 0.4.1 before any formicaria release linked it.

## What changes for people using formicaria

- **An app update brings the runtime it pins.** A runtime already on disk was never fetched again,
  so the faster runtime would only have reached new users. Myrme now records which runtime is
  installed; when the app's catalogue pins another, the new one is fetched aside and swapped in only
  once it is complete and verified.

## For formicaria

- The phone hosts Myrme through the facade too: `Bundled` (the runtime inside the APK and what
  Settings says about it), `Tools::provision_weights`, `Tools::installed_for` and
  `Tools::run_in_process`. formicaria's phone code lost about 250 lines of Myrme's insides.
- `Tools::runtime_outdated` and `Tools::refresh_runtime` for the runtime refresh.
- Contract 1.3 is an addition. `contract.md` lists the 1.0 items nothing uses any more, for 2.0.
