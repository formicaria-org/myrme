# Myrme 0.1.1 — an edit's kind is decided from the request alone

## What changes for people using formicaria

- Asked to *add a final line*, the assistant could replace a sentence that happened to contain the
  same words. It now first decides which kind of change was asked for (append, insert after,
  replace, delete, or several) from the request alone, and its edits are held to that kind.

## How it was found and checked

The live end-to-end run caught it; the evaluation had not, because it ran with no discussion history
and at temperature 0, which production never does. The edits evaluation now runs with both, and
reproduces the bug before the fix: 6/7 → 7/7 on qwen3-4b-2507 at production settings.
