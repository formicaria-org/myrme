# Myrme 0.3.0 — the desktop host's facade (contract 1.1)

## What changes for people using formicaria

- **Removing the downloaded model from Settings works again.** An installed copy took its own
  catalogue for a developer checkout and refused to delete anything.

## For formicaria

- **`fm_agent_run::host`**: formicaria's desktop asks Myrme what is installed, fetches it, removes
  it and starts it, through one type (`Tools`) over the folder the app gives Myrme, instead of
  reaching into Myrme's modules. The code, its messages and its tests moved here from formicaria's
  `fm-serve`.
- Contract 1.1 is an addition: everything in 1.0 stays while the phone still uses it.
- `pixi run integration` builds formicaria from inside its checkout, so the checkout's own Cargo
  settings apply.
