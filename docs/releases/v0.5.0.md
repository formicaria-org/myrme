# Myrme 0.5.0 — one source for the manual and the phone's runtimes (contract 1.4)

Nothing changes in how the assistant behaves. This release makes Myrme the only place that describes
it and decides what it runs, so formicaria keeps no copy of either.

## What changes for people using formicaria

- **The assistant's chapter of the user manual is written here** (`docs/manual/assistant.md`).
  formicaria's manual, in the app, in every download and on the website, renders it from the Myrme
  release it links, so the chapter always describes the assistant that ships.

## For formicaria

- Contract 1.4, an addition:
  - the catalogue carries the phone's runtimes: `runtime_url_android_arm64` with its hash, and
    `whisper_android_source`, the whisper.cpp tag the phone build compiles. formicaria's packaging
    reads them instead of keeping its own copy;
  - `docs/manual/assistant.md` is part of the contract, including the headings formicaria links to.
- **A version is released when its GitHub Release page is published.** CI publishes it only after
  the gate and the integration test pass on the tag, with notes from `docs/releases/`. formicaria's
  `myrme-bump` and its release take only published versions.
