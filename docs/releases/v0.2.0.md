# Myrme 0.2.0 — a contract formicaria can check (contract 1.0)

Nothing changes for people using formicaria. This release numbers what formicaria relies on.

## For formicaria

- **Two version numbers.** The release version (`fm_agent_run::VERSION`) changes every release;
  the contract version (`CONTRACT_MAJOR.CONTRACT_MINOR`, now **1.0**) changes only when what
  formicaria uses changes: a new major for a removal, rename or change of meaning, a new minor for an
  addition.
- formicaria states the contract it is written for and checks it at compile time, so an app built
  against an incompatible Myrme refuses to build and says why.
- `docs/context/releases.md` lists every release, its contract and the formicaria that links it.
- CI runs on every `v*` tag and refuses one that differs from `Cargo.toml`.
