# Myrme 0.4.1 — a model that fails to load is reported (contract 1.3)

Linked by formicaria 0.9.3.

## What changes for people using formicaria

- **A model that fails to load is reported within seconds.** The assistant used to wait 40 seconds
  for the model server and then announce itself ready although the server had already stopped. Now
  it stops as soon as the server exits and says so, on the desktop and on the phone, and the phone
  stops its transcriber with it.

## Checked

The live end-to-end run with both laptop models; with the model missing, agent-serve stops in about
four seconds with a message naming the file. `agents/e2e-live.sh` now accepts relative paths.
