# The user manual's assistant chapter

[`assistant.md`](./assistant.md) is the chapter on Myrme in
[formicaria's user manual](https://formicaria-org.github.io/formicaria/manual/). It is written here,
beside the code it describes, and formicaria renders it from the Myrme release it pins; formicaria
keeps no copy of its own.

Because it is rendered inside formicaria's book, its links to other pages (`./collaboration.md`,
`./notes.md`) resolve there, not on GitHub. Renaming a heading formicaria links to is a contract
change (`docs/context/contract.md`, part 3a).
